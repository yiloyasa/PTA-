## 二、Mobile Codex 插件完整架构

### 2.1 组件清单

| 组件 | 大小 | 说明 |
|------|------|------|
| mobile-codex-companion.exe | 18.2 MB | **核心伴侣服务** - HTTP 服务器 (7443) |
| mobile-codex-dex-plugin.exe | 8.0 MB | DEX 插件接口 - JSON-RPC 桥接 |
| mobile-codex-netd.exe | 30.2 MB | **网络守护进程** - Tailscale P2P |
| mobile-codex-shim.exe | 5.1 MB | ChatGPT 启动兼容层 |

### 2.2 技术栈确认
- **语言**: Go (Tailscale v1.100.0, Go 1.26.4)
- **P2P 网络**: Tailscale (WireGuard + Noise 协议)
- **控制平面**: Headscale (开源 Tailscale 控制服务器)
- **API 服务器**: HTTP/HTTPS on 7443
- **代理服务**: HTTP on 7444

### 2.3 工作流程
\\\
1. deecodex-gui.exe 启动
2. → 加载插件 deecodex-mobile-codex
3. → 启动 mobile-codex-dex-plugin.exe (JSON-RPC stdio)
4. → dex-plugin 启动 mobile-codex-companion.exe
5. → companion 启动 mobile-codex-netd.exe (Tailscale)
6. → companion 监听 7443 (HTTPS API)
7. → companion 监听 7444 (HTTP Proxy)
8. → Android APP 通过 Tailscale P2P 连接 7443
9. → 与 deecodex-gui.exe 通过 JSON-RPC 通信
\\\
