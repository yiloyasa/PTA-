### 4.3 通信协议
- **主协议**: gRPC (基于 HTTP/2)
- **备用协议**: JSON-RPC 2.0 over WebSocket/HTTPS
- **设备发现**: mDNS (局域网)
- **P2P 加密**: Noise Protocol (Tailscale)
- **身份认证**: Ed25519 签名 + JWT Token

## 五、关键发现

### 5.1 Ed25519 设备身份
- 使用 Ed25519 椭圆曲线加密算法
- 每个设备有唯一的密钥对
- 用于设备认证和 P2P 通信加密
- AndroidDeviceKeyStore 安全存储私钥

### 5.2 授权机制
`
1. 用户名/密码登录 → 获取 JWT Token
2. JWT Token 用于所有 API 请求
3. gRPC 使用 AuthorizationInterceptor 注入 Token
4. 设备身份使用 Ed25519 签名验证
5. Token 刷新机制 (/v1/auth/refresh)
`

### 5.3 Companion 发现流程
`
1. 启动 mDNS 服务发现 (NSD)
2. 在局域网中搜索 companion 设备
3. 获取 companion 的 TLS 证书指纹
4. 建立 TLS 加密连接
5. 通过控制平面验证设备身份
6. 建立 gRPC 通信通道
`
