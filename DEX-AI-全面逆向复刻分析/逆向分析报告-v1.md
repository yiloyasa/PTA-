## 三、主程序分析 (deecodex-gui.exe)

### 3.1 基本信息

- **导入表**: 无传统导入表 (RVA=0x1000, Size=0x0) - 动态加载 API
- **发现特征**: "NW" (NW.js 引用), "Go" (Golang 引用)
- **技术栈推断**: 可能基于 **NW.js** 或 **Go + WebView** 或 **Tauri**

### 3.2 代码特征
- 主程序使用动态 API 加载 (LoadLibrary/GetProcAddress 模式)
- 无 .NET CLR 头部

## 四、插件架构体系

### 4.1 通信协议
- **JSON-RPC 2.0** 通过 stdin/stdout 管道通信
- 主进程启动子进程插件，通过标准输入输出交换 JSON 消息
- 支持请求-响应模式和通知模式

### 4.2 插件初始化流程
1. 主进程发送 initialize 请求 (含 config/llm_base_url/data_dir)
2. 插件返回 name/version/capabilities
3. 主进程可发送 config.update 通知更新配置
4. 主进程发送 shutdown 通知关闭插件

### 4.3 插件类型
| 运行时 | 用途 | 示例 |
|--------|------|------|
| Node.js | 通道/自动化/工具 | weixin, 自动化模板 |
| Python | 数据源 | 数据源模板 |
| Binary | 原生二进制 | 同步/移动端插件 |

### 4.4 插件配置规范
- 每个插件通过 \plugin.json\ 声明
- 支持 features/methods/permissions/config_schema 等
- 插件可声明 account (账号系统)、features (功能列表)、dex_tools (工具暴露)

## 五、微信通道插件 (deecodex-weixin) 详细分析

### 5.1 功能概述
- 通过 **iLink Bot API** (腾讯微信官方接口) 接入微信
- 支持 QR 扫码登录
- 支持接收/发送文本消息、图片、视频、文件
- 支持 LLM 自动回复
- 白名单授权机制

### 5.2 API 接口
| 方法 | 作用 |
|------|------|
| \ilink/bot/get_bot_qrcode\ | 获取登录二维码 |
| \ilink/bot/get_qrcode_status\ | 轮询扫码状态 (2秒间隔，120秒超时) |
| \ilink/bot/getupdates\ | 长轮询获取消息 (35秒超时) |
| \ilink/bot/sendmessage\ | 发送消息 (文本/图片/视频/文件) |
| \ilink/bot/sendtyping\ | 发送"正在输入"状态 |
| \ilink/bot/getuploadurl\ | 获取媒体上传 URL |
| \ilink/bot/msg/notifystart\ | 通知 iLink 开始 |
| \ilink/bot/msg/notifystop\ | 通知 iLink 停止 |
| \ilink/bot/getconfig\ | 获取配置 |

### 5.3 消息处理流程
1. 长轮询获取消息 (\getupdates\)
2. 检查白名单授权
3. 加载对话上下文 (JSON 文件存储)
4. 调用 LLM (\llm.call\ RPC)
5. Markdown 过滤后发送回复
6. 保存上下文 (最多 50 条消息)

### 5.4 媒体处理
- 下载: CDN URL → AES-128-ECB 解密 → 本地存储
- 上传: AES-128-ECB 加密 → CDN PUT
- SILK 音频 → WAV 转码 (通过 ffmpeg 或 silk-v3-decoder)

### 5.5 配置项

{
  "base_url": "https://ilinkai.weixin.qq.com",
  "cdn_base_url": "https://novac2c.cdn.weixin.qq.com/c2c",

  "allowed_users": ["OpenID1", "OpenID2"],
  "max_context_messages": 50,
  "bot_agent": "deecodex",
  "bot_type": "3"
