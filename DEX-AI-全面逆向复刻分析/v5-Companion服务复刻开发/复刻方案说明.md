## 二、核心模块说明

### dex-companion (最核心)
监听 7443 端口，提供：
- HTTPS + WebSocket 服务
- JSON-RPC 2.0 协议
- JWT 认证
- mDNS 设备发现
- 与桌面端插件通信

### dex-core
- 插件生命周期管理
- JSON-RPC 消息路由
- 支持 Node/Python/Binary 三种插件

### dex-gui
- Electron 桌面窗口
- 对话界面 / 终端 / 文件管理
- 启动 Companion 子进程

### dex-control
- 账号注册/登录
- 设备管理
- JWT 签发

## 三、启动方式

```bash
# 1. 安装依赖
cd DEX-AI-复刻版
npm install

# 2. 启动 Companion 服务 (独立运行)
node dex-companion/src/index.js

# 3. 启动桌面端 (Electron)
npx electron dex-gui/src/main.js

# 4. 手机端连接
# 用 Android APK 连接电脑 IP:7443
```

## 四、与 Android 端通信流程

```
手机 APP                      Companion (:7443)              桌面端
   │                               │                          │
   │── mDNS 发现设备 ──────────────→│                          │
   │←── 设备信息 ──────────────────│                          │
   │                               │                          │
   │── wss://ip:7443/ws ──────────→│                          │
   │── JSON-RPC: initialize ──────→│── 转发 →─→                │
   │←── capabilities ──────────────│←── 响应 ──               │
   │                               │                          │
   │── JSON-RPC: thread/list ─────→│── 转发 →─→                │
   │←── threads ──────────────────│←── 响应 ──               │
   │                               │                          │
   │── JSON-RPC: fs/readFile ─────→│── 转发 →─→                │
   │←── file content ─────────────│←── 响应 ──               │
```
